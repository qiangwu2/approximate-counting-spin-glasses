## Endpoint and representation scope

The fixed model may supply exact model-dependent constants; these are fixed before runtime size, law and raw coupling values. No arbitrary real-returning function, target-result literal, supplied matrix evaluator, or free cost annotation is an instruction.

Inputs are ordinary labeled interaction records and an addressable raw random tape. The label/order equivalence specifies the input representation, and the same program works for every such equivalence. The cost model is the paper's ideal exact-operation model; it is not a bit-cost or floating-point claim.

The actual final output functions and failure/success/relative-success events are measurable by `OutputMeasurability`, including the canonical higher endpoint and the product color/disorder SK endpoint. The primitive execution equalities give precisely those output functions.
