## Machine and cost semantics

`RestrictedMachine.Instruction` has only integer real constants, natural constants, register copies, the displayed scalar arithmetic and elementary functions, comparisons, natural arithmetic, natural-to-real conversion, and addressed parameter/input/memory operations. There is no constructor accepting an arbitrary function or a desired real result. `Parameters` is a real array, but the endpoint fixes it from the model, temperature bound and field envelope before all runtime inputs. `RestrictedParameters.higher_model` and `sk_model` establish that coefficient reads agree with the intended fixed coefficients despite adjacent control/budget parameter blocks.

Every instruction's count is defined from its constructor. A constant write costs one, a register copy two, a binary operation four (two reads, computation, write), and a unary/cast/addressed operation three. Branches, repetitions and while tests add explicit positive control costs. A loop invariant or proof-indexed family of states does not become an instruction or an execution oracle.

The finite-procedure extension adds only syntactic calls into a fixed finite table. A call restores the explicitly listed registers and charges four per listed register plus five for call/return control. The semantic restoration is recursive over that fixed list; it restores no memory and gives access to no computed value other than the saved registers. This models a private ordinary call stack. The repeat instruction similarly models a private loop counter with charged copy/test/decrement/write operations. Neither mechanism exposes an uncharged whole-state snapshot to the program.

These are exact-real, unit-cost RAM semantics, including unbounded natural addresses and elementary functions, consistent with the manuscript's stated exact-operation convention. They do not claim a bit-complexity, finite-precision, or Lean-VM execution bound. Infinite zero-initialized memory is the standard RAM initial state; relevant SK memo and algebra arrays are additionally initialized by actual instructions.
